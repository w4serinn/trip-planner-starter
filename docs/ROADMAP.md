# ROADMAP

## 進め方の方針
- タスクはこの順で上から着手する: `0. 基盤` → Must機能(1〜6) → Should機能(7〜9)
- `0. 基盤`が完了するまで、他のセクションには着手しない(全機能がFirestore接続と
  画面シェルに依存するため)
- 1サイクル = 意味的にまとまった単位(目安: S/Mサイズ1〜3個)。詳細な1周の手順は
  `.claude/skills/evolve/SKILL.md`を参照
- サイズ目安: S = 数十行程度の変更、M = 1画面の主要機能一式

## 第2期: UI刷新(SPA化・企画メモ共有化・雑多メモ機能)

利用してみた人間からのフィードバックを受け、`docs/screens.md`「UI刷新方針」・
`docs/firestore-design.md`「UI刷新に伴うデータモデル変更」の通り2026-08-18に方針決定。
詳細な経緯・設計判断は両ドキュメントを参照。

`10`〜`16`(基盤SPA化・A/B画面移行・Cタブ構造化・企画メモ共有テキスト化・雑多メモ機能・
しおり時間UI変更・見た目の刷新)は全て完了済み(詳細はdocs/roadmap-done.md参照)。
旧MPA版(`pages/index.html`等)は削除済み。`index.html`(旧`app.html`)がプロジェクトルート
の唯一のエントリーポイント。企画メモ・雑多メモはそれぞれ`trips/{tripId}.planningNotesText`
・`scratchText`(単一共有テキスト、デバウンス自動保存)。雑多メモは選択範囲を
「→企画メモへ」「→しおりへ」ボタンで振り分け可能。しおりの時間入力は「午前/午後」
「時(0〜12)」「分(00/15/30/45)」の3セレクトボックス(保存形式は従来通り"HH:MM"文字列)。
配色はtabiori.com参考の明るい青×オレンジ基調に刷新済み(`styles/tokens.css`)。

第2期のタスクは以上で全て完了。現時点で他に未着手のタスクは無い。
